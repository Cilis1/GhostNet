GHOSTNET
own the network. pay the bill. lose what you name.
=====================================================================

START
  Double-click GhostNet.exe (or use the Start Menu shortcut "GhostNet").
  It runs in a console window. Windows Terminal looks best.

THE LOOP
  1. Open the Job board, pick a target, (optionally) scan it and ask the Panel.
  2. CONNECT. Every action costs connection time and the TRACE meter rises.
  3. Open the door: solve the lock in limited guesses, or type
     "phrase <word>" if you have read the maintenance passphrase somewhere.
  4. Inside: "ls", "cat <n>" to read, "get <n>" to download, "steal" for hardware.
  5. "disconnect" before the trace reaches 100%. Then the bill arrives.

LOCKS
  KEYPAD  4 different digits. HIT = right digit, right place; NEAR = right digit, wrong place.
  ROTOR   4 digits judged per wheel. "~" means ONE NOTCH AWAY (not misplaced!).
  CIPHER  5-letter word. [X] right place, (x) elsewhere in the word.

GHOSTNET (unlocks after your first contract)
  RELAY speeds downloads, PROXY slows the trace, SCOUT gives target reports,
  COMPUTE holds one emergency extra guess per run (type "extra" at a lock).
  Running machines bill you after every run and wear down. Arm a PROXY as bait
  and it dies in your place if you get traced.

THE PANEL
  VESPER (risk), LEDGER (money) and MOTH (intel) are advisor AIs in your deck.
  They read your meters and vote before every run. They never solve locks.

SAVES
  %APPDATA%\GhostNet\ghostnet_save.txt  (kept when you uninstall or update)

UPDATING / UNINSTALLING
  Run GhostNet-Setup.exe again to update or repair.
  GhostNet-Setup.exe --uninstall removes the game (your saves stay).
